# 천명도령 종합사주

## 참고한 공개 화면

- [용용사주 정통사주 소개](https://yongyong.ai/bot/880033/intro?category=all&from=home): 캐릭터 소개와 사주 확인 진입
- [청월아씨 정통사주](https://cheongwoldang.com/s/bluemoonladysaju): 캐릭터 이미지·영상에서 사주팔자 입력으로 연결되는 웹툰형 종합사주 소개

공개 소개 화면만 확인했습니다. 로그인·결제 후 전체 결과는 열람하지 않았으며, 해당 서비스의 본문·이미지·정확도 주장·후기를 복제하지 않습니다. 다점은 원래 저장소의 천명도령 이미지와 영상만 사용합니다.

## 기본 흐름

캐릭터 소개 → 이름·생년월일·한국 출생시각과 계산용 성별 → 전체 종합풀이 → 선택적인 추가 설명 순서입니다. 생년월일 입력 화면에서 고민·사연을 선택적으로 1,000자까지 적습니다. 기본 18개 장에는 사연을 전달하지 않습니다. 모든 생성 가능한 사주 근거를 종합한 별도의 고민 풀이 하나를 마지막에 표시합니다. 추가 상담에도 사연이 이어집니다. 사연이 없어도 전체 종합풀이를 생성합니다.

기존 Java 계산 엔진의 확정 해석 재료를 7개 영역에 걸쳐 모두 사용하며, 총 18개 장으로 구성합니다.

1. 나의 본질: 기질, 강점, 중심을 되찾는 방식
2. 사람과 인연: 사회적 관계, 가족, 거리와 갈등
3. 연애와 결혼: 사랑의 표현, 반복되는 패턴, 동반자 관계
4. 재물과 생활: 돈을 대하는 태도, 소비·관리, 기회와 부담
5. 적성과 일: 일하는 방식, 역량과 성과, 새로운 도전
6. 생활과 회복: 에너지와 생활 리듬, 회복 습관
7. 지나온 흐름: 실제로 지난 대운 기간에서 돌아볼 이야기

세운·월운·일운·두 사람 궁합은 계산하지 않으므로 지원한다고 표시하지 않습니다. 출생시간이 없거나 특정 장의 근거가 부족하면 미생성 안내로 구분합니다.

## 결과의 구성과 저장

장별 출력은 JSON 스키마로 구조를 지정하고 서버에서 장의 누락·중복·ID를 검증합니다. 장을 임의로 채우거나 질문을 유도하는 문장으로 대체하지 않습니다. 본문은 기존 이미지와 영상, 목차 사이에 이어집니다.

사용자가 보관을 선택한 종합풀이만 현재 브라우저의 기기에 최근 5개까지 저장합니다. 서버 세션은 1시간이며 재시작 시 사라집니다. 종합풀이를 읽은 뒤 12회까지 추가 설명을 요청할 수 있습니다. 기본 풀이에는 질문이 필요하지 않습니다.

## 장문 작성과 검증

기본 장은 1,500~1,900자, 마지막 고민 풀이는 2,200~3,000자입니다(공백 포함). 완전한 18개 장과 고민 풀이의 검증 범위는 29,200~37,200자입니다. 3개 장까지 병렬 작성하며 각 장의 근거, 해석 이유, 서로 다른 생활 예시와 적용 방법을 구체화합니다. 짧은 장은 부족한 설명을 두 번까지 보완하고, 긴 본문은 범위 안의 완결된 문장까지 정리합니다. 근거가 부족한 장은 생성하지 않으며, 실제 생성된 본문 분량을 표지에 표시합니다. 참고 서비스의 유료 본문이나 내부 풀이 알고리즘을 재현했다고 주장하지 않습니다.
