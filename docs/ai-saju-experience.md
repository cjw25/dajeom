# AI 사주 상담 경험

공개 서비스의 고민별 진입·대화형 상담·답변 길이 선택을 참고해, 다점의 사주 경험을 질문 중심으로 구성했습니다. 사례를 참고한 제품 설계이며 시장 점유율이나 정확도에 대한 주장은 하지 않습니다.

- [천명PLAY](https://chunmyung.com/contents): 고민 상담소, 관계 중심 AI 콘텐츠와 캐릭터 상담
- [사주나우 소개](https://sajunow.com/about): 질문형 상담과 설명 깊이 선택
- [포스텔러 공식 앱 소개](https://play.google.com/store/apps/details?hl=ko&id=com.un7qi3.forceteller): 주제별 진입과 다양한 운세 콘텐츠

## 이용 흐름

1. 여섯 가지 고민 중 선택하고 원하는 질문을 적습니다.
2. 닉네임·생년월일·한국 출생시각과 계산용 성별을 입력합니다. 현재 상황은 선택 입력입니다.
3. 핵심만·차분히·자세히 중 설명 길이를 고릅니다.
4. 사주 계산과 근거 준비를 먼저 실행하고 해당 고민에 대한 첫 답변만 생성합니다.
5. 같은 계산 결과로 후속 질문을 이어가거나 주제를 바꿉니다.
6. 원하는 경우에만 7개 전체 풀이를 펼치거나 상담을 기기에 저장합니다.

## 일관성

사주 계산은 기존 Java 엔진이 담당합니다. AI에는 현재 주제와 보조 성향의 확정 해석 재료, 본인이 설명한 상황, 서버가 보관한 대화를 전달합니다. 사용자 입력과 과거 AI 답변은 새로운 사주 판정의 근거가 아닙니다. 첫 답변과 후속 질문은 서로 독립된 원국 계산을 반복하지 않습니다.

출생시간을 모르면 세 기둥·여섯 글자의 오행을 표시하고 맞춤풀이는 생성하지 않습니다. 지나온 대운 기간의 근거가 없으면 과거 흐름도 생성하지 않습니다. 세운·월운·일운·두 사람 궁합은 아직 계산하지 않으므로 화면에서 지원한다고 표시하지 않습니다.

## 저장과 복구

서버 세션은 1시간, 한 상담당 첫 답변을 포함해 12회입니다. 생성 중 중복 요청은 거절하며, 실패한 질문은 대화와 횟수에 반영하지 않아 재시도할 수 있습니다. 전체 풀이 생성 결과는 같은 세션에서 재사용합니다.

대화는 자동으로 기기에 보관하지 않습니다. 사용자가 ‘내 기기에 저장’을 누르면 최근 5개까지 읽기 전용 기록을 보관합니다. 저장된 기록에서 서버 세션이 자동으로 복원되거나 다른 기기에 동기화되지는 않습니다. 공유 기능은 첫 답변의 핵심 문장만 사용합니다.
