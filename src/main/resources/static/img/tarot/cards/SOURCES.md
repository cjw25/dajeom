# Tarot card artwork

78 Rider–Waite–Smith card scans, Pamela Colman Smith / Arthur Edward Waite, originally published 1909.

Source: https://github.com/metabismuth/tarot-json/tree/e6414a098acc87831a8953bca7576b033b2fda54/cards
Upstream scans: http://data.totl.net/tarot-rwcs-images/
Repository license: MIT (included in LICENSE.txt). Original card artwork is identified as public domain by the source.

Original JPEGs are included without pixel modifications. Reversal is displayed with CSS rotation.
Mapping: m00–m21 = major arcana; w01–w14 = Wands; c01–c14 = Cups; s01–s14 = Swords; p01–p14 = Pentacles. Minor ranks: Ace, 2–10, Page, Knight, Queen, King.
